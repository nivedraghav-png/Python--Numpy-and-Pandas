# Python Assignment 1 – NumPy and Pandas

## 📌 Project Overview

This repository contains my Python assignment focused on **NumPy and Pandas**, two important libraries used in Data Science and Data Analytics.

The assignment covers basic array operations, statistical calculations, broadcasting, DataFrame creation, data filtering and CSV file handling.

## 🛠️ Technologies Used

* Python
* NumPy
* Pandas
* Jupyter Notebook

## 📚 Assignment Tasks

### 1. NumPy Array Creation and Reshaping

* Created a NumPy array containing numbers from 1 to 10.
* Reshaped the array into a 2 × 5 matrix.

### 2. NumPy Array Indexing and Slicing

* Created a NumPy array containing numbers from 1 to 20.
* Extracted elements between the 5th and 15th index using array slicing.

### 3. Statistical Operations

Calculated the following statistical measures using NumPy:

* Mean
* Median
* Standard Deviation

### 4. NumPy Broadcasting

* Created a 2D array `x` with shape (3, 4).
* Created a 1D array `y` with shape (4,).
* Subtracted `y` from each row of `x` using NumPy broadcasting.

### 5. Pandas DataFrame Operations

Created a DataFrame containing 10 rows with the following columns:

* Name
* Age
* Gender

Performed the following operations:

* Added a new column named `occupation`.
* Filtered records where age was greater than or equal to 30.
* Exported the DataFrame into a CSV file.
* Read the CSV file back into Pandas and displayed its contents.
